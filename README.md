Author: Éric Pouhier, 2025

Overview
---------
Audio laboratory of the Coupled Order Lattice System (COLS).
Each prime-power r=p^e becomes a voice; periods T_r are estimated on the
arithmetic signal S_r = 1 − h_r, then mapped to frequency f = K/T.
Optional 12-TET, chord tools, tempo-sync arpeggio, and WAV export. :contentReference[oaicite:14]{index=14}:contentReference[oaicite:15]{index=15}
